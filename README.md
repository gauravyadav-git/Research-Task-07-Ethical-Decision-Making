# Research Task 07 – Ethical Decision Making (Arsenal FC Case Study)

## 📌 Overview
This repository contains my submission for **Research Task 07: Ethical Decision Making**.  
The goal of this task was to create a **stakeholder-facing report** for Arsenal Football Club’s upper management (Edu Gaspar – Sporting Director and Richard Garlick – Managing Director). The report draws on insights from previous tasks (Task 05 – part 1 & 2, and Task 06) to evaluate Arsenal’s 2022–23 season and provide **tactical and strategic recommendations** for future success.  

---

## 🎯 Objectives of Task 07
- Analyze Arsenal’s performance in the 2022–23 season through descriptive statistics and contextual insights.  
- Identify gaps in **goal conversion, pressure management, and tactical adaptability**.  
- Present ethical considerations and bias awareness in decision-making.  
- Provide **recommendations** to strengthen squad depth, set-piece routines, and long-term competitiveness.

## 📊 Key Learning Outcomes
Through this task, I learned to:  
- Translate **quantitative football data** into actionable recommendations for decision-makers.  
- Balance **short-term tactical fixes** (goal conversion, set pieces) with **long-term strategy** (squad balance, experience).  
- Incorporate **ethical and bias considerations**, including dataset limitations and football-world pressures (e.g., media scrutiny).  
- Communicate findings in a **formal yet football-savvy format** suitable for senior management.
